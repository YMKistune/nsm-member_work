NSM MEMBER CLUB — RELEASE NOTES

1. รวม Dashboard ให้เหลือหน้าใช้งานหลัก dashboard.php และทำ dashboard_excel.php เป็นทางลัดไปหน้าเดียวกัน เพื่อป้องกันความสับสนระหว่าง Dashboard ซ้ำ
2. Dashboard ดึงจำนวนรายการและยอดสุทธิจากข้อมูล Excel ที่นำเข้า พร้อมเลือกเปรียบเทียบ 3 ปีงบประมาณ แสดงกราฟรายเดือนและตารางเปรียบเทียบรายเดือน
3. แยกตัวเลขสมาชิกจากผลงานพนักงานอย่างชัดเจน ไม่รวมจำนวนสมาชิก/ยอดสุทธิ Excel กับยอดผลงานพนักงาน
4. สร้างเมนูร่วมใน includes/navigation.php เพื่อลดความต่างของเมนูระหว่างหน้าและตัดลิงก์ซ้ำ
5. หน้ากรอกสมาชิกเดิม member_statistics.php และ member_online.php เปลี่ยนเป็นทางลัดไปหน้าข้อมูลจาก Excel; โค้ดเดิมเก็บไว้ใน _archive_reference/ และไม่มีการลบแถวฐานข้อมูล
6. ปรับตัวอ่าน XLSX ให้ใช้ path ของ Sheet แรกจาก workbook relationship และแปลง serial date ในคอลัมน์วันที่ที่รู้จัก
7. เพิ่มการใช้หัวข้อ Excel แบบ dynamic ในรายงานและกราฟ โดยนับจำนวนรายการตามค่าหัวข้อที่เลือก
8. ปรับ reports.php ให้แสดงรายงานสมาชิกจาก Excel และรายงานพนักงานแยกส่วน
9. เพิ่มตาราง member_online_monthly_entries และ member_online_monthly_notes ใน setup/migration เพื่อให้ schema เก่าที่ใช้งานอยู่ยังครบ โดยไม่ลบข้อมูลที่มีอยู่
10. เก็บ SQL dump เก่าและ test_db.php ไว้ใน _archive_reference/ แทนการวางปะปนในไฟล์ runtime

การตรวจสอบ: PHP lint ผ่านทุกไฟล์ runtime ในขณะจัดทำแพ็กเกจนี้
ยังต้องทดสอบกับ MySQL/XAMPP จริงและตรวจยอดเทียบกับ Excel ต้นฉบับก่อนใช้งานจริง


ตรวจทานต่อ 11 ต.ค. 2569
- ตรวจ PHP syntax ใน runtime ซ้ำอีกครั้ง: ผ่านทุกไฟล์
- ตรวจรายการเมนูหลักกับไฟล์ปลายทาง: พบไฟล์ปลายทางครบ
- ปรับเส้นทางติดตั้งใน README ให้ตรงกับชื่อโฟลเดอร์จริง nsm-member_work เพื่อป้องกันการแตก ZIP ซ้อนโฟลเดอร์และเปิด URL ผิด
- ยังไม่เปลี่ยน logic ธุรกิจหรือ schema เพิ่มเติม เพราะยังไม่มีข้อกำหนดปรับใหม่เฉพาะจุด และยังต้องทดสอบกับ MariaDB/XAMPP จริงก่อนยืนยัน end-to-end


รุ่นเพิ่มเติมกราฟ (11 ต.ค. 2569)
- เพิ่มกราฟเปรียบเทียบจำนวนรายการและยอดสุทธิแยกช่องทางในหน้าแยกประเภทข้อมูล โดยใช้ผลสรุปชุดเดิม
- เพิ่มกราฟ Package/กิจกรรมที่พบมากที่สุดในหน้าหมวดสมาชิก โดยใช้ตัวกรองเดียวกับตาราง
- เพิ่มกราฟ 5 กลุ่มกิจกรรมที่มีรายการสมาชิกมากที่สุดในหน้าออกบูธ โดยยึดผลที่ผ่านตัวกรอง
- เพิ่มกราฟสถานที่ที่พบรายการมากที่สุดในหน้าสิทธิ์เข้าชมพิพิธภัณฑ์
- เพิ่มกราฟ Package ที่พบรายการมากที่สุดในหน้า Member Lounge
- เพิ่มกราฟสัดส่วนสมัครใหม่/ต่ออายุในหน้าสมาชิก Active ภายใต้กติกาทดลองเดิม
- เพิ่มกราฟเปรียบเทียบยอดขายพนักงาน 10 อันดับแรกในหน้าผลงาน/KPI
- ไม่เพิ่ม/ลบตาราง SQL และไม่เปลี่ยนสูตรรายได้หลักหรือกฎจัดหมวดข้อมูล
- ตรวจ php -l และตรวจไวยากรณ์ JavaScript เบื้องต้น; ยังต้องทดสอบการทำงานจริงกับ MariaDB/XAMPP และข้อมูลของผู้ใช้


Update: เลือกหลายรายการเพื่อจัดหมวดหมู่พร้อมกัน
- หน้า member_categories.php เพิ่ม checkbox ต่อรายการและปุ่มเลือกทั้งหมดของรายการที่แสดง (สูงสุด 100 รายการ)
- เลือกปลายทางได้ 3 หมวดหลัก: สมัครที่ อพ., สมัครออนไลน์, ออกบูธ
- ก่อนส่งข้อมูลมีหน้าต่างยืนยันจำนวนรายการและหมวดปลายทาง
- ฝั่งเซิร์ฟเวอร์ตรวจสอบปีงบประมาณ หมวด และรหัสรายการ แล้วอัปเดตเฉพาะรายการที่ยัง source_section=unknown ภายในปีงบประมาณที่เลือก โดยใช้ transaction
- ไม่แก้ค่าคอลัมน์ต้นฉบับ Excel และไม่เพิ่ม/ลบข้อมูลสมาชิก
- จำกัดการเปลี่ยนหมวดไม่เกิน 100 รายการต่อครั้งตามรายการที่แสดง
- ยังไม่ได้ทดสอบกับฐานข้อมูล MariaDB/XAMPP จริง


11 ต.ค. 2569 — Grouped bulk categorization
- หน้า member_categories.php รวมรายการรอตรวจสอบที่มีช่องทาง/POS/กิจกรรม/Package/หมายเหตุเหมือนกันเป็นกลุ่ม
- ผู้ใช้เลือกหนึ่งหรือหลายกลุ่มและกำหนดหมวดปลายทางครั้งเดียว พร้อมแสดงจำนวนและตัวอย่างก่อนยืนยัน
- เปลี่ยนเฉพาะรายการ source_section='unknown' ในปีงบประมาณที่เลือก; ไม่แก้ค่า Excel ต้นฉบับ
- จำกัด 1,000 รายการต่อคำขอ และแสดงรายการสูงสุด 5,000 แถวต่อครั้ง

13 ต.ค. 2569 — Active rules and benefit usage preparation
- ปรับกฎ Active ให้ตรวจทั้งวันที่สมัครและวันหมดอายุ รวมวันเริ่ม/สิ้นสุด และแปลงปี พ.ศ. เป็น ค.ศ. ก่อนเปรียบเทียบ
- แยกรายการวันที่ว่าง/ผิดรูปแบบหรือช่วงวันที่ผิดปกติไว้ตรวจสอบ ไม่ให้นับเป็น Active
- เพิ่มตาราง benefit_usage_records สำหรับเหตุการณ์ใช้สิทธิ์จริงของพิพิธภัณฑ์และ Member Lounge โดยแยกจากรายการสมัครสมาชิก
- เพิ่มหน้า benefit_usage.php สำหรับบันทึกการใช้สิทธิ์จริงและดูสรุปรายบุคคล/จำนวนครั้ง/ประเภท/สถานที่/ค่าเฉลี่ย
- เพิ่มกล่องสรุปการใช้สิทธิ์จริงในหน้าพิพิธภัณฑ์และ Lounge; หากยังไม่มีข้อมูลจะแสดงว่ายังไม่มีข้อมูล ไม่สร้างยอดขึ้นเอง
- ย้ายเมนูออกบูธด้านนอกไปอยู่ภายใต้หมวดกิจกรรม
- เพิ่ม migration แบบสร้างตารางเพิ่ม ไม่ลบหรือแก้ข้อมูลสมาชิกเดิม

แนวทางตรวจปัญหา MariaDB error 1932 — NSM Member Club
====================================================

แพ็กเกจนี้แก้เฉพาะการแจ้งข้อผิดพลาดของระบบให้เข้าใจง่ายขึ้น และเพิ่ม SQL สำหรับตรวจสอบแบบไม่แก้ไขข้อมูล
ไม่ได้ซ่อมฐานข้อมูลจริง เพราะไม่สามารถเชื่อมต่อ XAMPP/MariaDB ในเครื่องของผู้ใช้จากที่นี่ได้

ก่อนเริ่ม
- หยุดนำเข้า Excel ชั่วคราว
- สำรองฐานข้อมูล nsm_member จาก phpMyAdmin ก่อนทุกการซ่อม
- ห้าม DROP TABLE, TRUNCATE, ลบไฟล์ฐานข้อมูล .ibd หรือ import ไฟล์ setup ทับฐานข้อมูลเดิม
- อย่าใช้ REPAIR TABLE กับ InnoDB เป็นวิธีแก้โดยเดา เพราะ REPAIR TABLE ไม่ใช่แนวทางซ่อมทั่วไปสำหรับ InnoDB

วิธีเก็บข้อมูลวินิจฉัย
1. เปิด phpMyAdmin แล้วเลือกฐานข้อมูล nsm_member
2. เปิดไฟล์ sql/diagnose_excel_import_tables.sql ใน ZIP
3. รันคำสั่งทีละรายการในแท็บ SQL
4. บันทึกผลลัพธ์ โดยเฉพาะ selected_database, information_schema.TABLES, SHOW TABLE STATUS และ CHECK TABLE
5. ส่งผลลัพธ์กลับมาเพื่อตรวจสอบก่อนเลือกวิธีซ่อม

หมายเหตุ
- รหัส 1932 มักหมายถึง MariaDB เห็น metadata ของตาราง แต่ storage engine เปิดตารางไม่ได้
- CREATE TABLE IF NOT EXISTS จะไม่แก้ตารางที่ค้าง/ไม่สอดคล้องใน engine โดยอัตโนมัติ
- โค้ดในแพ็กเกจจะไม่พยายามลบหรือสร้างตารางทับเอง เพื่อหลีกเลี่ยงการสูญหายของข้อมูล
- หลังซ่อมฐานข้อมูลจริงแล้ว ควรทดสอบหน้า import และ dashboard ใน XAMPP อีกครั้ง

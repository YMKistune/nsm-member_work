NSM MEMBER CLUB — EXCEL-FIRST RELEASE
====================================

เป้าหมายของรุ่นนี้
- ใช้ Excel ที่บริษัทส่งออกเป็นแหล่งข้อมูลสมาชิกหลัก: นำเข้า → ตรวจหมวด → ดู Dashboard/รายงาน
- ใช้ Dashboard หลักเพียงหน้าเดียวที่ dashboard.php
- แยกตัวเลขสมาชิกออกจากตัวเลขผลงานพนักงาน ไม่รวมจำนวนหรือรายได้เข้าด้วยกัน
- คงตารางและข้อมูลเก่าของระบบไว้ ไม่ลบข้อมูลจากฐานข้อมูล
- หัวข้อ Excel ใหม่จะถูกเก็บใน extra_data ก่อน และตั้งค่าให้แสดงในตาราง/ตัวกรอง/รายงาน/กราฟได้

ติดตั้งใหม่ (ฐานข้อมูลว่างเท่านั้น)
1. แตก ZIP แล้วนำโฟลเดอร์ nsm-member_work ไปไว้ที่ C:\xampp\htdocs\nsm-member_work\ (อย่าให้ซ้อนเป็น nsm-member_work\nsm-member_work)
2. เปิด XAMPP และ Start Apache + MySQL
3. เปิด phpMyAdmin แล้ว Import sql/nsm_member_complete_setup.sql
4. เปิด config/database.php ตรวจ host, database, user และ password ให้ตรงกับเครื่อง
5. เปิด http://localhost/nsm-member_work/dashboard.php
6. เข้า “นำเข้า Excel” แล้วเลือกไฟล์ .xlsx ที่บริษัทส่งออก

สำคัญ — ฐานข้อมูลที่ใช้งานอยู่แล้ว
- สำรองฐานข้อมูล nsm_member ก่อนเปลี่ยนไฟล์หรือรัน SQL ทุกครั้ง
- ห้าม Import sql/nsm_member_complete_setup.sql ทับฐานข้อมูลจริง เพราะไฟล์ setup มีข้อมูลตั้งต้น/คำสั่งตั้งค่าระบบเก่าเพื่อการติดตั้งใหม่
- ถ้ามีฐานข้อมูลเดิมแต่ยังไม่มีตาราง Excel: Import sql/excel_data_import.sql ก่อน
- จากนั้น Import sql/migration_dynamic_excel_headers.sql เพื่อเพิ่มความสามารถหัวข้อใหม่และสร้างตารางออนไลน์เดิมที่อาจขาด โดยใช้ CREATE TABLE IF NOT EXISTS/การเพิ่มคอลัมน์แบบตรวจสอบก่อน
- หากไม่แน่ใจว่าโครงสร้างฐานข้อมูลปัจจุบันเป็นรุ่นใด ให้สำรองฐานข้อมูลและให้ผู้ดูแลตรวจ schema ก่อนรัน migration

ลำดับการใช้งานหลัก
1. Dashboard — ภาพรวมจากรายการ Excel, เลือก 3 ปีงบประมาณ, กราฟและตารางเปรียบเทียบรายเดือน
2. นำเข้า Excel — ตรวจไฟล์ซ้ำ, บันทึกประวัติการนำเข้า, แยกหมวดข้อมูล, แจ้งหัวข้อที่ไม่รู้จัก
3. สมัครที่ อพ. / สมัครออนไลน์ / ออกบูธ — ตารางและตัวกรองของแต่ละหมวด
4. เปรียบเทียบ 3 ส่วน / ตรวจสอบหมวดข้อมูล — ตรวจการจัดกลุ่มและรายการที่ยังไม่แน่ใจ; ระบบรวมรายการที่มีช่องทาง/POS, สถานที่/กิจกรรม, Package และหมายเหตุเหมือนกันเป็นกลุ่ม ให้เลือกกลุ่มและกำหนดหนึ่งใน 3 หมวดพร้อมกันได้ (สูงสุด 1,000 รายการต่อครั้ง)
5. สมาชิก Active / สิทธิ์เข้าชมพิพิธภัณฑ์ / Member Lounge — วิเคราะห์จากคอลัมน์ที่มีอยู่ใน Excel เท่านั้น
6. กิจกรรมออกบูธ / โปรโมชั่น-ส่วนลด — แยกข้อมูลกิจกรรมและรายการที่มีส่วนลด/บัตรกำนัล
7. จัดการหัวข้อ Excel — ตั้งค่าหัวข้อใหม่ให้แสดงในตาราง เป็นตัวกรอง หรือใช้ทำสรุปจำนวนรายการในรายงาน/กราฟ
8. งานพนักงาน — จัดการพนักงาน, บันทึกการปฏิบัติงาน และ KPI แยกจากข้อมูลสมาชิก

การจัดการ Excel
- ระบบรองรับไฟล์ .xlsx และอ่าน Sheet แรกของไฟล์
- ถ้าพบไฟล์เดิมที่มี SHA-256 hash เดียวกัน ระบบจะป้องกันการนำเข้าซ้ำ
- หัวข้อที่รู้จักจะถูกเก็บลงคอลัมน์หลัก ส่วนหัวข้อใหม่จะถูกเก็บใน extra_data เพื่อไม่ทำค่าต้นทางหาย
- หัวข้อใหม่เริ่มต้นเป็น “รอตรวจสอบ” ต้องเพิ่มเข้าระบบก่อน แล้วจึงกำหนดหมวด/การแสดงผล
- ควรตรวจรายการ “ยังไม่จัดหมวด” ก่อนนำตัวเลขไปใช้ในรายงานทางการ; หน้าแยกประเภทข้อมูลรวมรายการที่มีข้อมูลช่องทางและกิจกรรมเหมือนกันเป็นกลุ่ม ผู้ใช้เลือกกลุ่มแล้วกำหนดหมวดพร้อมกันได้ โดยเปลี่ยนเฉพาะรายการที่ยังไม่จัดหมวด
- ระบบพยายามอ่านวันที่ Excel ที่เก็บเป็นเลข serial และแปลงเป็นวันที่ก่อนคำนวณปีงบประมาณ

ข้อควรอ่านก่อนตีความตัวเลข
- “ยอดสุทธิ” จาก Excel ใช้เป็นตัวเปรียบเทียบชั่วคราวเท่านั้น จนกว่าจะยืนยันนิยามรายได้กับบริษัท
- จำนวนรายการไม่จำเป็นต้องเท่ากับจำนวนสมาชิกไม่ซ้ำ หาก Excel มีหลายรายการต่อสมาชิก
- การจัดหมวด AP/Online/Booth ใช้ค่าช่องทาง, POS, สถานที่/กิจกรรม และหมายเหตุ หากไม่ชัดจะเก็บเป็น “ยังไม่จัดหมวด” แทนการเดา
- หน้า Active ใช้วันหมดอายุและสถานะตามกติกาที่แสดงในหน้า ต้องยืนยันนิยาม Active กับบริษัทก่อนใช้อ้างอิงทางการ
- ข้อมูลใน Excel ไม่ได้ยืนยันการใช้สิทธิ์เข้าชมพิพิธภัณฑ์หรือ Member Lounge จริงโดยอัตโนมัติ หากไม่มีคอลัมน์บันทึกการใช้สิทธิ์
- หัวข้อใหม่ที่ตั้งค่า “รายงาน/กราฟ” จะแสดงเป็นการนับจำนวนรายการตามค่าของหัวข้อนั้น ไม่ได้ตีความเป็นยอดเงินโดยอัตโนมัติ

หน้าและไฟล์สำคัญ
- dashboard.php — Dashboard หลัก ใช้ข้อมูลสมาชิกจาก Excel และแสดงผลงานพนักงานเป็นบล็อกแยก
- excel_import.php — นำเข้าไฟล์ Excel
- includes_excel_data.php — โครงสร้าง/ตัวช่วยสำหรับตารางข้อมูล Excel
- section_data_page.php — หน้าตารางร่วมของหมวด AP/Online/Booth
- excel_fields.php — ตั้งค่าหัวข้อ Excel ที่เพิ่มใหม่
- reports.php — รายงาน Excel และรายงานพนักงานแยกส่วน
- employees.php / work_record.php / performance.php — โมดูลพนักงาน
- config/database.php — การเชื่อมต่อ MySQL
- sql/nsm_member_complete_setup.sql — ติดตั้งฐานข้อมูลใหม่
- sql/excel_data_import.sql — สร้างตาราง Excel หากฐานข้อมูลเดิมยังไม่มี
- sql/migration_dynamic_excel_headers.sql — migration เพิ่มเติมแบบไม่ลบข้อมูล
- _archive_reference/ — ไฟล์เก่า/สำเนา SQL เพื่ออ้างอิงเท่านั้น ไม่มีการ include จากระบบหลัก

การทดสอบที่ทำในแพ็กเกจนี้
- ตรวจ syntax ของไฟล์ PHP ทั้งหมดที่อยู่ใน runtime
- ตรวจเส้นทางเมนูและยืนยันว่า Dashboard หลักมีเพียง dashboard.php (dashboard_excel.php เป็นทางลัดเปลี่ยนเส้นทาง)
- ตรวจว่าระบบหลักไม่มีคำสั่ง DROP TABLE, TRUNCATE หรือ DELETE ข้อมูลสมาชิก
- ตรวจโครงสร้าง SQL สำหรับตารางที่โค้ดใช้งานและเติม schema ของตารางออนไลน์เดิมที่ขาด

ข้อจำกัดการทดสอบ
- สภาพแวดล้อมจัดทำแพ็กเกจนี้ไม่มีส่วนขยาย pdo_mysql, ZipArchive และ SimpleXML ที่ครบสำหรับเปิดเว็บกับ MySQL และนำเข้าไฟล์จริง จึงยังไม่ได้ทดสอบ end-to-end ใน XAMPP/เบราว์เซอร์
- ก่อนใช้งานจริง ให้ทดสอบบนสำเนาฐานข้อมูลก่อน โดยเฉพาะการนำเข้า Excel และตรวจตัวเลขกับ Excel ต้นทาง

การจัดการหัวข้อ Excel:
- เปิด ตั้งค่าระบบ > จัดการหัวข้อ Excel เพื่อดูรายการหัวข้อหลักและหัวข้อเพิ่มเติม
- ลงทะเบียนชื่อหัวข้อใหม่ล่วงหน้าได้ และเลือกจับคู่กับช่องมาตรฐานของระบบได้
- หากพบหัวข้อใหม่ระหว่างนำเข้า ระบบเก็บค่าที่ไม่รู้จักไว้ใน extra_data และแจ้งให้ตรวจสอบ
- การจับคู่ที่กำหนดหลังนำเข้าใช้กับไฟล์ครั้งถัดไป ไม่ย้ายค่าของข้อมูลเก่าโดยอัตโนมัติ
- ต้องมีคอลัมน์ mapped_to_header ใน excel_dynamic_columns; ระบบจะเพิ่มให้อัตโนมัติเมื่อมีสิทธิ์ ALTER TABLE หรือรัน sql/migration_excel_header_mapping.sql ก่อนใช้งาน
- ส่วน “จัดการประเภทสมาชิก” ถูกนำออกจากหน้าตั้งค่าหลัก แต่ไม่ลบตารางหรือข้อมูลเดิม
